# Design direction — EGR spending site

User direction (2026-10-07): "keep the site a clean egr look" — referencing https://www.eastgrmi.gov.

## What that means
Echo the City of East Grand Rapids' own visual identity, not a generic gov template:
- Clean white background, deep municipal navy/blue as the primary brand color (matching the city's site palette)
- Simple, confident sans-serif typography; clear hierarchy
- Uncluttered, civic, trustworthy — the way the city's own site feels

## But elevated
The user also asked for NYT data-viz / Apple simplicity / Stripe-level polish. So:
- Take EGR's clean civic palette (white + deep blue) as the foundation
- Add restrained data-viz color accents (teal/green/amber for charts only, never partisan red/blue)
- Lots of whitespace, large typography, mobile-first
- NOT government-looking in the boring-template sense; NOT patriotic red/white/blue; NOT partisan; NOT corporate-cold

## Hard rules (from user brief)
- No "gotcha" aesthetics — no red alert styling, no alarmist visuals
- Flags read as calm, neutral "worth understanding" cards, not warnings
- Plain-English labels everywhere; accounting codes secondary
- Every number traceable; methodology page visible
